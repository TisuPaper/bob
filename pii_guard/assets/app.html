Supported outputs & setup notes

Install the logVeil Python package in your application environment. The guard protects existing StreamHandler and FileHandler text outputs, including standard rotating files. Configure logging first; handlers added later need protect_handler(handler, policy). Replacing a protected formatter removes protection.

Queue, socket, HTTP and custom emitters need their own integration. This does not intercept print(), direct file writes or other languages. Counters are local observations, not proof that every output is protected; one application process should write each status file.
